## Context & Objectives
A second, independent check: generate many random programs, compute the expected result with an **oracle you write from the spec only**, and compare with the real `Interpreter`. Do not read `minicalc/evaluator.py` or `minicalc/parser.py` before writing the oracle. You may read them afterwards only to explain a mismatch you found. This task targets the Presentation criterion ("advanced features or optimizations", "deep understanding").

## Specific Scope & Deliverables
1. **`tests/oracle.py`:** a self-contained reference semantics for MiniCalc values written from the spec (do not import anything from `minicalc` except `INT_MIN`, `INT_MAX` for the range). It evaluates a small expression tree of your own design and returns either an int or an error class name (`"DivisionByZeroError"`, `"IntegerRangeError"`, `"DomainError"`). Implement truncating division, floor division, floored modulo, `**` rules, comparisons, and the unary/range behavior from the spec.
2. **`tests/test_differential.py`:**
   - A seeded generator (`random.Random(seed)`, seeds fixed in the file) producing random expression trees over `+ - * / // % **`, comparisons, unary minus, `abs`, `min`, `max`, `gcd`, with operand magnitudes drawn from mixed distributions (small, around 46340, around 2**31, powers of two) so overflow, zero divisors, and negative exponents all occur frequently.
   - A printer that renders a tree to MiniCalc source in **two ways**: fully parenthesized, and minimally parenthesized using the spec's precedence/associativity table. Both renderings must produce the same result as the oracle (this tests the parser's precedence independently of the evaluator).
   - Compare `Interpreter().run_line(src)` against the oracle: equal values, or the same error class. When the oracle reports an error, only the error **class** is compared. Run at least 2,000 expressions per rendering (fixed seeds, deterministic, total runtime under 15 s).
   - Variable-state test: random sequences of 20 assignments and expressions (including failing ones) checked against an oracle-side dictionary, verifying atomicity and `ans` after failures.
   - On any mismatch the assertion message prints the seed, the source text, the oracle result, and the actual result.
3. **Mutation sanity check** (run locally, record in the report, do not commit the mutants): temporarily change the evaluator in three ways (`/` floors instead of truncating; `%` uses truncated remainder; `**` is left-associative in the parser) and show that the differential test fails for each. Restore the code.
4. **Audit report** (sections: Independence Certification stating which files you read and when; Method; Results with number of expressions per category; Mismatches; Mutation results; Residual risks). If you find real mismatches, do not fix `minicalc/`; list them for INT-001-style triage.
