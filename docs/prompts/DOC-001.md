## Context & Objectives
The rubric's top Documentation band requires "clearly and effectively documented including descriptions of **all class variables**". [D-11] turns that into a mechanical standard. This task adds an automated checker and brings the whole package up to it **without changing any behavior**.

## Specific Scope & Deliverables
1. **`scripts/check_docs.py`** (standard library only, uses `ast`). For every `*.py` under `minicalc/` (and `main.py`):
   - module docstring present;
   - every class has a docstring; if the class has any attribute (class-level annotation or assignment, dataclass field, enum member, or `self.x = ...` assigned in `__init__`), the docstring must contain an `Attributes:` section and **every attribute name must appear in it** (`name:` or `name (type):` at the start of a line);
   - every public function and method (no leading underscore, plus `__init__`) has a docstring; if it has parameters (other than `self`/`cls`) it must contain `Args:`; if it contains a `return` with a value, `Returns:`; if it contains a `raise`, `Raises:`.
   - Output: a list of `path:line: message` violations; exit code 1 if any, 0 otherwise; a summary line `N classes, M functions checked`.
   - Self-test it: `tests/test_check_docs.py` with temp-file fixtures for a passing module and for each violation type.
2. Run the checker, then fix every violation with Google-style docstrings (`Attributes:`, `Args:`, `Returns:`, `Raises:`). Explain **why**, not only what: for example, for `Token.pos` explain that it feeds error carets; for `Environment.ans` explain when it is set and cleared.
3. **No behavior change.** Prove it: write a one-off script (do not commit) that compares `ast.dump` of every module, with docstring expression statements removed, between `HEAD~1` and the working tree; paste its "identical" output into the report. Also `pytest -q` must be unchanged.
4. Add short inline comments only where logic is non-obvious (precedence climbing, truncating division, the `**` short-circuit); do not comment trivialities.
