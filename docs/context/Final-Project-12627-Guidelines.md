***Final Project Guidelines***


I. **Groupings**

A group is composed of a minimum of 3 members and a maximum of 5 members. You may form and select your own group. Cross-grouping is allowed – a member from a group came from other section.


II. **Project Requirements**

General requirements: 

	For your final project, 

1. you will be creating a simple programming language that can process simple arithmetic operations with a minimum computation requirement of integer values.

2. Your program should handle errors like incorrect format.

3. Your program should present correct output.

4. The PL should follow the PL evaluation criteria.

5. Proper documentation of the source code.


III. **Final Requirements**

1. There are already libraries that you can utilize for easy creation of this project. However, you need to learn those libraries properly.

2. Submit the source code of your project through a ZIP file and upload it in a google drive. The ZIP file should contain your source code with proper documentation.

3. Submit the shared GDrive link through the MVLE Course Final Project Submission Thread.

4. Deadline of submission: October 30, 2026, 17:00
